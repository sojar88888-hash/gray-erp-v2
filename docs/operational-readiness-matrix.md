# GRAY ERP — مصفوفة الجاهزية التشغيلية

**حالة الوثيقة:** `ISOLATED IMPLEMENTATION / PRE-GO-LIVE`  
**مرجع الحوكمة:** `docs/governed-implementation-note.md` و`docs/expanded-erp-scope.md`  
**قرار التنفيذ:** يمكن استكمال التشغيل الإداري والتجاري المقيد، لكن لا يجوز تفعيل أي ترحيل أو اعتماد مالي أو قيد دفتر أستاذ حتى إغلاق PRE-01 إلى PRE-08 وC.1 بأدلة قابلة للتحقق. يعرض الخادم حاليًا PRE-01 إلى PRE-06 كطبقة جاهزية تنفيذية، بينما PRE-07 وPRE-08 متطلبات حوكمة مستقبلية مستقلة ضمن قرار الإطلاق.

## مفتاح الحالة الموحّد

| الحالة | المعنى التنفيذي |
|---|---|
| `live` | الوظيفة موجودة خلف صلاحيات الخادم ويمكن استخدامها في حدودها المعلنة. |
| `setup-required` | الوظيفة موجودة، لكنها لا تعرض بيانات أو لا تسمح بإنشاء سجل حتى يهيئ المدير نطاق الشركة أو البيانات المرجعية. |
| `governed-blocked` | الوظيفة محظورة عمدًا إلى أن تسجل أدلة حوكمة بشرية وفنية قابلة للتحقق. |
| `out-of-scope` | الوظيفة غير مخططة لهذه النسخة؛ لا توجد واجهة أو خدمة تدّعي دعمها. |

## تعريف «جاهز للتشغيل» في هذه المرحلة

يعني الجاهز للتشغيل أن مدير النظام يستطيع تهيئة الشركة والفروع، إدخال البيانات الأساسية، إنشاء مستندات متعددة البنود وتمريرها عبر دورة تشغيلية مقيدة، تنفيذ تحويلات المخزون وحركات المستندات التشغيلية وتسويات الجرد، إنشاء مسودات قبض وصرف غير مرحلة، تتبع أثر التدقيق، وطباعة نسخ حية ومراجعة تقارير التشغيل. ولا يعني ذلك السماح بإنشاء قيود أو اعتماد مالي أو تسوية بنكية أو كشوف أو قوائم مالية.
