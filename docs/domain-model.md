# GRAY ERP — نموذج المجال للنسخة الأولى

يرتكز نموذج المجال على الفصل بين **المستند المصدر** و**الحركة التشغيلية** و**الأثر المحاسبي**. لا يُنشأ الأثر المحاسبي في هذه النسخة، لكن تعرّف كياناته وعلاقاتها لضمان عدم الحاجة إلى إعادة تصميم جذرية عند الانتقال إلى المرحلة المحكومة.

| النطاق | الكيانات الأساسية | الغرض |
|---|---|---|
| المؤسسة والصلاحيات | شركة، فرع، مستخدم، دور، نطاق بيانات | عزل البيانات وتحديد من يقرأ أو ينشئ أو يعتمد |
| تجاري | عميل، عرض، أمر بيع، فاتورة بيع، تحصيل | تتبع دورة الإيراد من العرض إلى التحصيل |
| مشتريات | مورد، طلب شراء، أمر شراء، استلام، فاتورة مورد، دفعة | توثيق الالتزام والتوريد قبل الأثر المالي |
| مخزون ووقود | منتج، مستودع، خزان، حركة مخزون، عدّ فعلي، تسوية | احتساب الرصيد من الحركات بدل رقم ثابت |
| عمليات | مركبة، سائق، رحلة، تسليم، قراءة عداد، استثناء | ربط الحركة الميدانية بالمستندات التجارية والمخزون |
| محاسبة | دليل حسابات، فترة مالية، قيد، سطر قيد، دفتر عام | هيكل محجوز للترحيل المحكوم لاحقًا |
| رقابة | حدث تدقيق، طلب اعتماد، مرفق دليل | تتبع الفاعل والتغيير والسياق دون تعديل صامت |

تُستخدم حالات المستند كقيم صريحة مثل `مسودة` و`قيد المراجعة` و`معتمد` و`ملغي`. وتُحفظ الكميات والمبالغ كقيم عشرية، بينما تحفظ التواريخ التشغيلية بتوقيت UTC في طبقة البيانات وتُعرض محليًا في الواجهة.
