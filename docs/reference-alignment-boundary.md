# حدود مواءمة نماذج GRAY GROUP المرجعية

## الغرض والنطاق

تُستخدم النماذج التي سلّمها مالك النظام مرجعًا معتمدًا لـ **الهوية البصرية**، وترتيب المعلومات، وكثافة العرض، وأنماط البطاقات، وتكوين معاينات المستندات. ويشمل ذلك لوحة القيادة الداكنة، ونموذج عرض السعر، ونموذج فاتورة المبيعات، ونموذج سند القبض.

لا تُعدّ هذه المواءمة، بذاتها، اعتمادًا لتصميم عملية محاسبية أو سياسات ضريبية أو تسلسل أرقام مستندات أو صلاحيات مالية.

| العنصر المرجعي | ما سيُعتمد في النظام | الحد الحوكمـي الصريح |
| --- | --- | --- |
| لوحة القيادة | التدرج الداكن، الهوية البرتقالية، التسلسل البصري، كثافة البطاقات، المجموعات التحليلية، الإجراءات السريعة | لا تُعرض قيم أو اتجاهات أو عمليات خيالية؛ تعتمد البطاقات على بيانات النظام أو حالات فارغة صريحة. |
| عرض السعر | رأس المستند ثنائي اللغة، مناطق المرسل/المستلم، جدول البنود، الإجماليات والملاحظات | المعاينة لا تشكّل عرضًا معتمدًا ولا تثبّت رقمًا أو قيمةً أو التزامًا تجاريًا. |
| فاتورة المبيعات | تكوين رأس الفاتورة، تفاصيل الأطراف، جدول البنود، المساحات المخصصة للشروط والتوقيع | المعاينة لا تُصدر فاتورة رسمية، ولا تحسب ضريبة أو تنشئ ذممًا أو حركات مخزون أو قيودًا. |
| سند القبض | رأس السند، حقول وسيلة الدفع، بيان المستلم، مساحة المبلغ والملاحظات والتواقيع | المعاينة لا تُنشئ قبضًا أو حركة خزينة/بنك أو قيد يومية أو توقيعًا أو ختمًا معتمدًا. |

## قواعد التنفيذ

تعتمد الواجهة أصول شعار GRAY GROUP المسلّمة من المالك ومجموعة الألوان المستخلصة من النماذج: كحلي داكن، أبيض محايد، وبرتقالي للتمييز. لا يُنشأ توقيع أو ختم أو رمز QR أو معلومات اتصال أو قيم مستندات جديدة من دون مصدر نظامي موثوق.

تعرض معاينات المستندات حاليًا شارة **مسودة / غير معتمدة**. وتظل إجراءات اعتماد المستند، والقبض، والترحيل، وإصدار القوائم الرسمية مقيدة ببوابة الجاهزية المالية وإجراءات صلاحيات الخادم القائمة.

> **حد عدم التنفيذ:** لا يترتب على أي تغيير في هذه الواجهة إنشاء مستند مالي رسمي، أو عملية نقدية، أو قيد يومية، أو أثر على دفتر الأستاذ العام.
