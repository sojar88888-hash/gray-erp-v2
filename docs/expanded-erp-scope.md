# GRAY ERP — نطاق التوسعة والبوابات المالية

## نطاق النسخة الموسعة

توسّع هذه النسخة واجهة GRAY ERP إلى مركز تحكم مؤسسي عربي عالي الكثافة يشمل الإدارة العامة، المبيعات، المشتريات، المخزون، النقد والبنوك، المشاريع، الأصول الثابتة، الموارد البشرية، التقارير، الحوكمة، والإعدادات. تعرض لوحة القيادة مؤشرات واقعية عندما تتوفر بيانات معتمدة، وحالات جاهزية صريحة عندما لا تتوفر؛ ولا تستخدم بيانات مالية مصطنعة في أي تقرير أو بطاقة قرار.

## نموذج التنفيذ

تصنف هذه التوسعة حاليًا **ISOLATED IMPLEMENTATION**. يسمح التطبيق بإدارة الإعدادات والبيانات الأساسية والمستندات التشغيلية ضمن الصلاحيات، وبعرض المؤشرات والمخاطر وحالة الجاهزية. ولا يسمح بإنشاء أثر مالي رسمي أو اعتماد أو ترحيل أو إصدار قوائم مالية رسمية.

| المسار | الحالة في النسخة الموسعة | قيد الحوكمة |
|---|---|---|
| لوحة القيادة والتحليلات | متاح بحالات بيانات حقيقية أو فارغة | لا تظهر قيم تقديرية أو بيانات تجريبية |
| المبيعات والمشتريات والمخزون | متاح كأساس تشغيلي مضبوط | كل تغيير خادمي يُنسب للمستخدم ويسجل في التدقيق |
| النقد والبنوك والمشاريع والأصول والموارد البشرية | متاح كمساحات عمل وإعداد ورقابة | لا تسويات أو استهلاك أو كشوف رواتب أو ترحيل فعلي |
| دفتر الأستاذ والقيود | محجوب | يتطلب حوكميًا PRE-01 إلى PRE-08، مع بقاء C.1 كحكم إطلاق مستقل موثقًا؛ ويعرض الخادم حاليًا PRE-01 إلى PRE-06 كطبقة جاهزية تنفيذية فقط. |
| التقارير المالية الرسمية | محجوب | يتطلب بيانات مرحّلة ومصالحة واعتمادًا مصدقًا |
| اعتماد المستندات | محجوب | لا يُنشأ اعتماد إلا من خدمة مصادق عليها مولدة لدليل اعتماد |

## مؤشرات الجاهزية

يجب أن يبقى شريط حالة المالية في الواجهة على **محجوب حوكميًا** إلى أن تتحقق، بأدلة قابلة للتحقق، المتطلبات الآتية: سياسة سنة مالية وعملات، دليل حسابات بإصدار ساري، قواعد ربط موثقة، فصل Maker/Checker/Poster، هوية معتمدة للمالك والموافق، بيئة QA وعقد اختبار، والمصالحة وسجل الأدلة.

> لا يعتبر وجود المستخدم في المتصفح أو نص الموافقة أو إعداد واجهة المستخدم دليلًا على وجود سلطة ترحيل أو اعتماد مالي.
